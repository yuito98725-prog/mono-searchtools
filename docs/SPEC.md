# 仕様書 (docs/SPEC.md)

## 1. プロジェクト名称
- **名称**: 型式、物品検索AI (Mono Finder AI)

## 2. 目的・背景
従来の型式完全一致検索やキーワード検索では、「年式や用途はわかるが型式がわからない」「既存の廃番部品の後継品を探したい」「寸法や仕様から適合する工業部品を割り出したい」といった現場の課題を解決できません。また、一般的な生成AIは存在しない型番や誤った適合情報を確信を持って出力するハルシネーションのリスクがあります。

本システムは、**「対象を特定 → 情報を検索 → 根拠を評価 → 回答」** という4段階の厳密なプロセスを踏むことで、AIの単独知識による断定を排除し、信頼できる一次情報・メーカー公式情報の根拠URLを添えて正確な回答を提供することを目的とします。

---

## 3. 対象範囲
本システムは対象分野を限定せず、幅広い実体製品（モノ）をカバーします。
- 産業用部品（ベアリング、空圧・油圧機器、直動案内機器、カップリング等）
- 機械部品・機構部品・FA機器
- 電気・電子部品（スイッチ、コネクタ、リレー、センサー等）
- 自動車部品（補修部品、油脂類、消耗品、カスタムパーツ等）
- バイク・オートバイ部品（フィルター、パッド、プラグ、チェーン等）
- 工具・測定機器・作業用品
- 家電製品・住宅設備・消耗品（リモコン、替え刃、フィルター等）
- デジタル機器・OAサプライ
- 一般消費財・生活用品
- 銘板や型式が不明な既存製品の後継機・互換品

## 4. 入力仕様
### 4.1 入力形式
- 自由形式の自然言語チャット入力
- 型式・品番が判明している入力（例: `NTN 6204ZZ`, `BKR6E-11`）
- 条件・用途・特徴からの検索（例: `外径47 内径20 幅14の深溝玉軸受`）
- 車種・年式等を含む検索（例: `2014年式CB1100のオイルフィルター`, `BMアクセラ2.0 6MTのブレーキパッド`）
- 後継品・代替品調査（例: `オムロン製近接センサ E2E-X10MF1 の後継機種`）

### 4.2 フロントおよびバックエンドでの入力制限
| 項目 | 制限値 | 備考 |
| :--- | :--- | :--- |
| 最小文字数 | 2文字 | 空白のみ・1文字はバリデーションエラー |
| 最大文字数 | 300文字 | 長文によるプロンプト肥大化・DoS対策 |
| 空白トリム | 必須 | 前後の不要空白は自動除去 |
| 危険文字・構文 | 制御文字除外 | 制御文字（NULL文字等）を拒否 |

## 5. 情報源の優先順位と適合性判定

### 5.1 情報源優先順位テーブル
| 優先度 | 情報源種別 (`sourceType`) | 区分 | 採用方針 |
| :---: | :--- | :--- | :--- |
| **1** | メーカー公式製品ページ | `official` | 最優先採用。型番・寸法・仕様の基準とする。 |
| **2** | メーカー公式カタログ・PDF | `official_pdf` | 最優先採用。図面・交差・適合表を含む一次情報。 |
| **3** | メーカー公式パーツリスト・取説 | `official_manual` | 車両や機器の純正品番特定における最上位根拠。 |
| **4** | 公的機関・規格認証機関の一次情報 | `primary_public` | JIS規格、ISO、車検基準、安全基準等。 |
| **5** | 正規販売店・認定データベース | `authorized_distributor` | ミスミ、モノタロウ公式スペック表、正規代理店。 |
| **6** | 大手総合EC・一般販売サイト | `general_marketplace` | 価格や流通参考のみ。**適合性の断定には使用禁止**。 |
| **7** | その他Web情報・ブログ・SNS | `reference` | 補助的情報。断定根拠としては採用しない。 |

### 5.2 適合性・信頼度ランク判定
| 確度 (`confidence`) | 判定基準 | 挙動 |
| :---: | :--- | :--- |
| **高 (`high`)** | メーカー公式ページ/PDF/パーツリストで完全一致が確認できた場合 | 適合または型式を断定して案内 |
| **中 (`medium`)** | 複数の信頼できる情報源（正規代理店・複数カタログ）で一致が確認できた場合 | 確からしい候補として案内し、注意事項を付記 |
| **低 (`low`)** | 一般ECサイトや二次情報のみしか確認できない場合 | 断定せず「参考候補」として提示。実機確認を促す |
| **不明 (`unknown`)** | 情報源間で矛盾がある、または十分な根拠が見つからない場合 | 差異の内容を明記し、追加情報の入力を促す |

## 6. 車・バイク部品の特別取扱規定
車・バイクの部品適合は人命や車両故障に関わるため、以下の安全運用を義務付けます。

1. **必要確認事項の明示**
   - 自動車・バイク部品の検索時は、原則として以下の照合を試みる：
     - メーカー、車種名、初度登録年式、車両型式（例: DBA-BMEFS）、エンジン型式（例: PE-VPR）、トランスミッション区分（AT/MT/CVT）、グレード、仕向地、純正品番
2. **情報不足時の安全動作**
   - 型式指定番号・類別区分や年式マイナーチェンジにより適合が分かれる場合、**絶対に勝手に断定しない**。
   - `needsMoreInformation: true` とし、不足しているパラメータを `followUpQuestion` に格納してユーザーへ尋ねる。
3. **車台番号の個人情報保護**
   - ユーザーから車台番号が入力された場合であっても、システムログやデータベースに**恒久保存しない**。検索処理完了後にメモリから破棄する。

## 8. エラーハンドリング仕様
- **入力不正 (Validation Error)**: 400 Bad Request 相当（UIに親切なエラーメッセージを表示）
- **認証/App Check エラー**: 401/403 相当（App Check検証失敗。不正な直接APIアクセスを拒否）
- **タイムアウト/検索不能**: 504/500 内部エラー時、内部スタックトレースや内部URL・鍵情報は一切返さず、「安全に情報を取得できませんでした。時間をおいて再試行してください」と汎用メッセージを返す。
